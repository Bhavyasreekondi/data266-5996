STEP 4: Chunking
Status: Completed

Chunking Strategy 1:
Fixed-word chunking

Parameters:
- Approximately 180 words per chunk.
- 40-word overlap.

Chunking Strategy 2:
Sentence-window chunking

Parameters:
- Approximately 180 words per chunk.
- Sentence boundaries preserved.
- One-sentence overlap.

Both strategies were applied to all 100 documents.

STEP 5: Embedding Generation
Status: Completed

Embedding model:
sentence-transformers/all-MiniLM-L6-v2

Embeddings were generated separately for both chunking strategies and normalized before indexing.

STEP 6: Vector Database
Status: Completed

Vector database:
ChromaDB

Collections created:
- fixed_word_collection
- sentence_window_collection

Each collection stored:

- Chunk text.
- Chunk ID.
- Source document ID.
- Chunking strategy.
- Embedding vector.

STEP 7: Baseline Retrieval
Status: Completed

At least two sample queries were evaluated.

The top five chunks were retrieved using vector similarity search without reranking.

The retrieved results included:

- Chunk ID.
- Source document ID.
- Distance score.
- Chunk text.

STEP 8: Reranking
Status: Completed

Reranking model:
cross-encoder/ms-marco-MiniLM-L6-v2

The system first retrieved candidate chunks and then reranked them using the CrossEncoder.

Both chunking strategies were tested with and without reranking.

STEP 9: Conversational Memory
Status: Completed

A simple conversational-memory mechanism was implemented.

The memory stored:

- The previous user query.
- The previous retrieved context.

A follow-up query depended on the first query and was evaluated with and without conversational memory.

STEP 10: Evaluation Metrics
Status: Completed

The following metrics were calculated:

- Precision@5.
- Recall@5.
- Mean Reciprocal Rank.

Relevance was manually defined using source document IDs.

STEP 12: Main Finding
Status: Completed

Fixed-word chunking without reranking and sentence-window chunking without reranking achieved the same highest average score of 0.9667.

Reranking did not improve performance for the current queries.

The results are preliminary because only a small number of queries were evaluated.
