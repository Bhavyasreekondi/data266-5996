and compare the representations before and after fine-tuning.

Target words:

screen
review


Environment / Libraries:
- Python
- Gensim
- Pandas
- NumPy
- scikit-learn
- Matplotlib

300

PART 2: RETRIEVAL-AUGMENTED GENERATION
======================================

Objective:
Build a RAG pipeline from ten Wikipedia movie pages using explicit LangChain
components.

Wikipedia movies used:
- The Dark Knight
- Inception
- Interstellar
- Titanic
- The Matrix
- Forrest Gump
- Gladiator
- The Shawshank Redemption
- Jurassic Park
- The Godfather


Document loader:
LangChain WebBaseLoader

WikipediaLoader was initially attempted but the Wikipedia API returned a
non-JSON response, causing a JSONDecodeError. WebBaseLoader was used instead.

Number of source documents:
10


Baseline text splitting:
RecursiveCharacterTextSplitter

chunk_size = 500
chunk_overlap = 50


Embedding model:
sentence-transformers/all-MiniLM-L6-v2

Embedding dimension:
384


Vector database:
FAISS

Retriever:
Top-k = 3


LLM:
Qwen/Qwen2.5-0.5B-Instruct

An initial attempt was made with google/flan-t5-base. The installed Transformers
environment did not support the intended text2text-generation pipeline, and the
direct FLAN-T5 model generated unreliable responses during validation.
Qwen2.5-0.5B-Instruct was therefore used for the final RAG experiment.


Explicit RAG components:
1. Document loader
2. Text splitter
3. Hugging Face embedding model
4. FAISS vector store
5. Top-3 retriever
6. LangChain PromptTemplate
7. Qwen instruction-tuned LLM


Official five evaluation questions:

1. What song is used as an audio cue to synchronize actions across dream levels
   in Inception?

2. What is the name of the ship that strikes an iceberg in Titanic?

3. Who plays Neo in The Matrix?

4. What prison is Andy Dufresne sent to in The Shawshank Redemption?

5. Which dinosaur is responsible for many of the attacks in Jurassic Park?

RAG failure 1:
Inception audio-cue question

The retriever returned passages related to music, dream levels, and synchronized
"kicks", but the actual answer-bearing passage containing the song title was
not present in the Top-3 results. The model generated "Inception: Kick", which
was unsupported by the retrieved context.

Failure type:
Retrieval failure followed by generation failure.


RAG failure 2:
Jurassic Park dinosaur question

The baseline retriever returned mostly a section heading and citation/reference
material rather than the relevant plot evidence. The model consequently
returned "Mottram 2021, p. 32."

Failure type:
Retrieval failure followed by generation failure.


Alternative chunking experiment:

chunk_size = 1000
chunk_overlap = 100

The alternative configuration was tested on the two failed questions.


Inception alternative result:
Relevant answer-bearing passage in Top-3: No

Retrieved chunks remained related to Inception, music, dreams, and film themes,
but did not contain the required song evidence.

Generated answer:
"Penrose stairs are incorporated into the film as an example of the impossible
objects that can be created in lucid dream worlds."

Result:
No retrieval improvement.


Jurassic Park alternative result:
Relevant answer-bearing passage in Top-3: Yes
First relevant rank: 1

Rank 1 contained plot text stating that a Tyrannosaurus rex escapes and attacks
the touring group.

Generated answer:
"Dinosaurs are responsible for many of the attacks in Jurassic Park."

Result:
Retrieval improved, although generation remained overly generic and incorrect.
